# joy-cabin-compare

Compare Norwegian Cruise Line's published cabin prices on the Norwegian Joy, Nov 20, 2026, 3 nights round trip from Miami to Nassau and Great Stirrup Cay.

- Pick the number of adults and kids (with ages) and see every cabin category's price, cabins left, taxes, Free at Sea gratuities and service charges.
- Prices are read from NCL once a day by a GitHub Actions workflow. This page compares rates; it does not book or hold cabins.

See `NOTES.md` for how it works and `CHANGELOG.md` for versions.
